- **2026-07-30** — **101 subclasses granted nothing because one JSON file was never opened.** Phase B1 of `flutter_app/docs/open5e_content_audit.md`, the audit's headline content defect, fixed in [[build_packs]] (loads `ClassFeatureItem.json`) + [[mapper_chargen]] (new `_levelFeatures`). `ClassFeature` carries no level; its child `ClassFeatureItem` does, and the mapper's own header comment had conceded that for months. Result on the rebuild: `class.features` 100% (2/2), `subclass.features` and `granted_at_level` **99.0% (100/101)**, **572 level rows** — reconciled exactly against the pinned `d4276c58` snapshot (561 non-table features, 4 of which span more than one level), so the mapper drops nothing and invents nothing. **The discriminating detail is that `ClassFeatureItem` holds two different things.** A feature whose items *all* carry a `column_value` is a class-table *column* — `Proficiency Bonus`, `Augment Effects Known`, spell slots: 9 features, 171 rows — and emitting those as features would have produced 20 identical "features" per column. They belong to **B2**'s typed `*_by_level` fields. No shipped document mixes the two shapes inside one feature, which is what turns "every item has a `column_value`" from a heuristic into a safe test. A feature that *improves* gets one row per distinct level, with upstream's `detail` (`'2 dice'`, `'two attacks'`) carrying the follow-up rows since it is the only thing distinguishing them. `subclass.granted_at_level` = the lowest level the subclass's own non-table features arrive at. **The 101st subclass is a source hole, not a bug**: `Path of Hellfire` (`open5e-toh`) ships a `CharacterClass` row and **zero** `ClassFeature` rows upstream, so there is no level to read; filling it would be invention, and it stays the one subclass `subclass_step.dart`'s default-to-1 keeps pickable at level 1. New `test/tool/class_feature_levels_test.dart` (7 cases) drives fixture → `mapClasses` → [[character_resolver]] and asserts the rows land on the sheet at the right level (Barbarian 2 → nothing, 3 → the level-3 row, 14 → all three), that class-table columns are excluded, and that a feature with no `ClassFeatureItem` invents none. - **2026-07-29** — **Package→package links.** The built-in pack and the official Open5e packs ship the same races/classes/items/spells twice, and the only sharing mechanism was hard-coded: `srdReferenceEntitiesProvider` overlaid SRD into every other package, `SrdCoreBootstrap` linked SRD into every world — the idea worked but could not be pointed at anything else.
