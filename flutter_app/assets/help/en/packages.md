# Packages

A **package** is a reusable bundle of cards: a bestiary, a spell book, a region. Build it once, import it into any [world](help:worlds) on a matching [template](help:templates).

## Packages tab

- **Create Package**: name and template, optionally starting with the SRD content.
- **Open** a package to edit its cards; it works like the [Codex](help:codex).
- **Built-in** packages are read-only. **Copy** one for an editable version.
- **Delete** moves it to the Trash. Worlds that imported it keep their cards.

## Linked packages

A package can **link** others instead of copying them. Linked content stays in its own package but shows up inside this one, follows its updates, and comes along when this package is imported into a world or downloaded. Deleting a package others link to breaks those links; the app warns first.

## Using a package

- In a world: **Import Package**. Fields are matched by key; what the world's template lacks is kept but not shown. [Codex](help:codex)
- In an [online world](help:online-play) the DM can **share a package** with all players.

## Online & sharing

- **Take Package Online**: keeps it in sync across your devices. Packages have no live updates; they sync when opened, at app start, sign-in and reconnect. **Take Package Offline** removes the cloud copy.
- Publish it to the [marketplace](help:marketplace), or send a `.dmtz` file. [Saving & your data](help:saving)

Packages on your own template stay on this device: no online, no marketplace.
