# Mind Map

An endless board for plot threads, faction ties, mysteries and session prep.

## Nodes

- **Note**: a title plus **Markdown**; `@` mentions link to [Codex](help:codex) cards.
- **Card**: shows a Codex card on the board.
- **Image**: right-click a node to set its image.
- Drag a node to move it, drag a corner to resize.
- **Connect** nodes to show relations; right-click a connection to delete it.

## Drawing

**Pen** (color, thickness), **Eraser**, and **Move** to go back to moving nodes.

## Workspaces

Separate boards inside one world, for example one per arc. **Center View** brings you back if you get lost.
