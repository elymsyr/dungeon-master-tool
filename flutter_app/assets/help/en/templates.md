# Templates

A **template** is a game system's skeleton: which **categories** exist (Monster, Spell, Location…), which **fields** each card has, and how they are laid out. Every [world](help:worlds) and [package](help:packages) is built on one and keeps its own copy. [How it fits together](help:concepts)

## Two kinds

| | Built-in D&D 5e (SRD 5.2.1) | Your own template |
|---|---|---|
| Editable | No (**View**, **Copy**) | Yes (**Edit**, **Rename**, **Delete**) |
| Rules | Built in: creator, level up, rests, computed sheet | None: blank sheet, guide, level tables, grants, rests you set up |
| Online / marketplace | Yes | Not yet: stays on this device |

A ready-made, read-only **D&D 5e (SRD 5.2.1) - Free Template** is also listed, with a locked SRD package on it, if you want the SRD on the free system without building it yourself.

## Making your own

- **Copy** the built-in template: all its categories, fields and layout, with D&D-specific field types turned into general ones. The copy ships with a 13-step character guide.
- **New empty template**: only the player card, with **Level** and **Pool** fields ready.
- **Copy** one of your own templates to branch it, for example a "low magic" variant.

Then edit it. [Template editor](help:template-editor)

## Changes and worlds

- Saving an edit does not touch any world. The next time a world on that template opens, it offers the update; card values are never changed.
- Deleting or renaming a template breaks nothing; worlds and packages keep their copy, they just stop getting updates.
- **Transfer** exports a template alone as a `.dmtz` file. [Saving & your data](help:saving)
