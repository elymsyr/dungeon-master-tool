# Saving & Your Data

## Autosave

Every edit is written to the local database about a second after you stop typing. The indicator in a world's top bar shows the state:

| State | Meaning |
|---|---|
| **Auto-saving…** | A change is being written. |
| **Saved** | Everything is on disk. |
| **In sync with the cloud** | Online content only: the cloud copy is up to date. |
| **Offline** | Changes are safe here and go up when you are back online. |
| **Sync problems** | Tap for details and **Retry**. |

**Undo / Redo** (Ctrl+Z / Ctrl+Shift+Z) sit in a world's top bar.

## The cloud is opt-in

Only content you take online gets a cloud copy:

- an **online world**, so players can join ([Playing online](help:online-play));
- an **online package**, to have it on your other devices ([Packages](help:packages)).

How it syncs: a few seconds after an edit, the changed rows go up; when the world opens or the connection comes back, changes from the cloud come down. If the same thing is edited on two devices, the later edit wins. Online content you own that is not on this device shows under **In the cloud, not on this device**; press **Download** to get it.

## Moving content without an account: `.dmtz`

**Transfer** on a world, package, character or template:

- **Export to file (.dmtz)**: one zip with the content and its media.
- **Import from file (.dmtz)**: merges the file into this device.

Use it for backups, or to move content between devices with no account and no network.

## Trash

Deleted worlds, packages and characters go to the **Trash** (Settings → Trash). They can be restored for **30 days**, then they are deleted for good. **Empty Trash** deletes everything now. [Settings](help:settings)
