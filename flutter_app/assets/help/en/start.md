# Getting Started

Dungeon Master Tool runs a tabletop campaign in one app: lore, maps, combat and players. It is **offline-first**: everything is stored on this device, and the cloud is used only for content you take online.

## Hub tabs

| Tab | Holds |
|---|---|
| **Worlds** | Your campaigns. [Worlds](help:worlds) |
| **Characters** | Every character you own, across worlds. [Characters](help:characters) |
| **Templates** | Game systems: categories, fields, layout. [Templates](help:templates) |
| **Packages** | Reusable card bundles. [Packages](help:packages) |
| **Social** | Feed, messages, game listings, marketplace. [Social](help:social) |

Settings open from the profile menu. [Settings](help:settings)
