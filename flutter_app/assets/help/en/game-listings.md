# Game Listings

## Posting

Fill in **title**, **description**, **seats**, **schedule**, **game language**, **system** and **tags** (`5e`, `roleplay`, `beginner-friendly`…), then **Post listing**.

**My listings** shows each listing's **applicants**. Message them, **Close** the listing when the table is full, or **Delete** it.

## Applying

Filter by **language**, **system** or **tag**. **Apply** with a short intro: timezone, experience, what you enjoy. **Withdraw** takes it back.

Once accepted, the DM sends an invite code. [Playing online](help:online-play)
