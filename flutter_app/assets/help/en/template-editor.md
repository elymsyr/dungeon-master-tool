# Template Editor

Opened with **Edit** on one of your templates. Changes save automatically.

## Layout

- **Desktop**: three panels. Left: template sections and **Categories**. Middle: the selected category's layout (groups and fields as boxes you drag). Right: settings of the selected field, group or category. Bottom: the palette; drag a style or preset into the middle, or click it.
- **Phone**: nested pages; **+ Add** opens styles and presets; drag the handle to reorder; a group's settings are in its menu.
- **Preview** switches the middle panel to the real card view.

## Categories, groups, fields

- **Categories**: add, rename, set icon and color. The **player card** category always exists and cannot be deleted.
- **Groups**: **Add group**, column count, **Start collapsed**. Deleting a group keeps its fields.
- **Fields**: **Add field**, label, key, **Required**, visibility (everyone or DM only), width, **Holds several values** (makes it a list).

Changing a field's style: if old values can't be read in the new style, a new field replaces it and the old values stay hidden on the cards. Deleting a field keeps its data hidden too; adding it back restores it.

## Styles

**Simple:** Text, Long text, Markdown, Integer, Decimal, Checkbox, Choice, Date, Tags, Dice, Image, Era image, File / PDF, Card link.

**Combined:**

| Style | Holds |
|---|---|
| **Table** | Rows with your columns; fixed rows set by the template, or free rows cards add. |
| **Stat table** | Scores and their modifiers. |
| **Skill table** | Skill / save rows: proficiency marks, stat and total. |
| **Resource** | A current / max counter; each rest fills it, empties it or leaves it. |
| **Level table** | What a card gives level by level: text to read and grants. |
| **Grants** | Items a card passes to whoever carries it. |
| **Combat stats** | HP / Max HP and the values the encounter shows. |
| **Pool** | Granted items that no list takes, resources included. |

**Presets**: save a field as a preset and reuse it in several categories; settings live in the preset, values stay per card.
